# Ai-learning

Public learning and AI-tool projects by Ziyang Xu.

## Projects

- [Sheet Shadow](./sheet_shadow) - a safe MCP bridge that helps AI agents edit real Excel workbooks without blindly rewriting them.
- [PiMoa](./PiMoa) - an MCP server that gives your coding agent a Mixture-of-Agents panel: several models propose in parallel, one aggregates the verdict, and read-only verification runs inside an OS sandbox. **v2** cut a real audit from 53s-and-failed to 22.7s-and-correct by fixing why external MoA blows up where in-house sub-agents don't.
