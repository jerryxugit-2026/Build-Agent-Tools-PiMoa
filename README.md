# Ai-learning

Public learning and AI-tool projects by Ziyang Xu.

## Projects

- [Sheet Shadow](./sheet_shadow) - a safe MCP bridge that helps AI agents edit real Excel workbooks without blindly rewriting them.
- [PiMoa](./PiMoa) - an MCP server that gives your coding agent a Mixture-of-Agents panel: several models propose in parallel, one aggregates the verdict, and read-only verification runs inside an OS sandbox. Bilingual README (中文 / English).
